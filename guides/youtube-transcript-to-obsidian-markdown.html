How to save a YouTube transcript to Obsidian as Markdown

Last updated: November 21, 2026

Short answer: export the transcript as a Markdown file and save it into your Obsidian vault. A good export starts with the title, channel and link, keeps chapters as headings, and turns timestamps into links back to the video.

With a Chrome extension (one click per video)

I make a free extension for this, YouTube Transcript & Subtitle Exporter.

  1. Open the video and click the Transcript button next to Subscribe.
  2. Choose MD and click the button under it. A .md file named after the video is saved.
  3. Move the file into your vault folder (or set Chrome to save downloads there), and it shows up in Obsidian as a note.

The note starts with the title, channel, link, duration and export date, followed by the video description, chapter headings (if the video has chapters) and the text. With Timestamps on, each timestamp links to that second of the video. Under Options you can join auto-caption lines into paragraphs and remove sound tags like [Music].

Prefer to paste? Choose Copy instead and paste into a new note.

Without an extension

  1. Under the video, expand the description and click Show transcript.
  2. Select the text in the panel, copy it, and paste it into a new note.
  3. Add the title and link yourself, and clean up the timestamps on each line.

This works for a single short video. For long videos, or if you clip videos often, the extension saves a lot of cleanup.

This needs a video with captions (uploaded or auto-generated). For videos without captions, see how to get a transcript of a video without captions.

FAQ

How do I get a YouTube transcript into Obsidian?

Export the transcript as a Markdown (.md) file and save it into your vault folder, or copy the text and paste it into a new note. A transcript extension can create the Markdown with the title, link and timestamps for you.

Can the timestamps link back to the video?

Yes. In the extension's Markdown export with timestamps turned on, each timestamp is a link to that second of the video.

Does it include chapters?

If the video has chapters, the Markdown export adds them as headings, so the note follows the structure of the video.

Does this work in Notion too?

Yes. Notion imports Markdown files and pastes Markdown text, so the same export works there.

Can I remove [Music] and other sound tags?

Yes. The extension removes [Music], (Applause), (Laughter), ♪ and >> speaker marks from Markdown, TXT and copied text by default.
